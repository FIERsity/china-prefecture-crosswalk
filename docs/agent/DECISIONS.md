## 新增决定的格式

新增一行时应回答四件事：

1. 实际选择了什么；
2. 为什么该选择会长期影响实现；
3. 后续 Agent 必须遵守或复核什么；
4. 它是否替代某个旧决定。

实现细节、一次性修复和版本变化通常属于 `CHANGELOG.md` 或 [`STATUS.md`](STATUS.md)，不属于本表。
