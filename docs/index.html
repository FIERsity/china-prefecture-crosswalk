04 / DATA NOTES

数据说明

数据分为研究实体、年末状态、年内名称匹配、地级行政单位变更和县级变更记录。查询年份统一按年末口径；连续改名当年的新旧名称均可匹配，结果返回年末名称。事件查询窗口为1983—2026，年末状态和名称层为1987—2026；两组年份是数据覆盖范围，不是所有名称的真实生效起止年。
